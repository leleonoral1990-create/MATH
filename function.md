### Этап 1. Область определения функции $D(f)$

**Объяснение:**
Это множество всех значений переменной $x$, при которых функция «существует» (ее можно вычислить). Мы ищем «запретные зоны».

* **Дробь:** знаменатель не равен 0.
* **Корень четной степени:** подкоренное выражение $\ge 0$.
* **Логарифм:** аргумент $> 0$.

**Пример:**
Для функции $f(x) = \frac{5}{x - 3} + \sqrt{x + 1}$:

1. $x - 3 \neq 0 \Rightarrow x \neq 3$.
2. $x + 1 \ge 0 \Rightarrow x \ge -1$.
**Итог:** $D(f) = [-1; 3) \cup (3; +\infty)$.



### Этап 2. Область значений функции $E(f)$

**Объяснение:**
Область значений функции (множество значений) — это все возможные значения, которые может принимать зависимая переменная $y$ (функция) при переборе всех допустимых значений независимой переменной $x$ из области определения. Геометрически область значений представляет собой проекцию всего графика функции на вертикальную ось ординат ($Oy$).

В то время как область определения показывает, где график существует по горизонтали, область значений показывает, какие границы график имеет по вертикали.

Основные способы нахождения $E(f)$:

1. **Оценка алгебраических выражений:** использование базовых свойств (любой квадрат $\ge 0$, модуль $\ge 0$, корень $\ge 0$).
2. **Свойства тригонометрических функций:** использование встроенных ограничений (например, $-1 \le \sin(x) \le 1$).
3. **Использование производной:** нахождение абсолютных максимумов и минимумов функции на ее области определения.
4. **Выражение $x$ через $y$:** решение уравнения $y = f(x)$ относительно $x$ для поиска ограничений на $y$.

**Примеры:**

* **Пример 1 (Квадратичная функция):**
$f(x) = x^2 - 3$
Поскольку квадрат любого действительного числа не может быть отрицательным ($x^2 \ge 0$), то минимальное значение всего выражения достигается при $x = 0$ и равно $0 - 3 = -3$. Верхней границы нет.
**Итог:** $E(f) = [-3; +\infty)$
* **Пример 2 (Тригонометрическая функция):**
$f(x) = 2\cos(x) + 1$
Известно, что функция косинуса ограничена: $-1 \le \cos(x) \le 1$.
Умножаем все части неравенства на 2: $-2 \le 2\cos(x) \le 2$.
Прибавляем ко всем частям 1: $-1 \le 2\cos(x) + 1 \le 3$.
**Итог:** $E(f) = [-1; 3]$
* **Пример 3 (Дробно-рациональная функция):**
$f(x) = \frac{1}{x} + 2$
Дробь $\frac{1}{x}$ может принимать любые значения, кроме нуля (так как числитель не равен нулю). Следовательно, выражение $\frac{1}{x} + 2$ может быть любым числом, кроме $0 + 2 = 2$.
**Итог:** $E(f) = (-\infty; 2) \cup (2; +\infty)$



### Этап 3. Четность, нечетность и симметрия графика

**Объяснение:**
Исследование на четность и нечетность позволяет значительно упростить построение графика функции. Если функция обладает одним из этих свойств, достаточно исследовать и построить ее график только для положительных значений $x$ ($x \ge 0$), а затем отразить полученную кривую по правилам симметрии.

Функция проверяется путем подстановки $-x$ вместо $x$ в исходное уравнение:

1. **Четная функция:**
* **Условие:** $f(-x) = f(x)$ для любого $x$ из области определения.
* **Свойство графика:** График симметричен относительно вертикальной оси ординат ($Oy$). То есть правая и левая половины графика являются зеркальным отражением друг друга.


2. **Нечетная функция:**
* **Условие:** $f(-x) = -f(x)$ для любого $x$ из области определения.
* **Свойство графика:** График симметричен относительно начала координат (точки $O(0; 0)$). Если перевернуть график на 180 градусов, он совпадет сам с собой.


3. **Функция общего вида:**
* **Условие:** $f(-x) \neq f(x)$ и $f(-x) \neq -f(x)$.
* **Свойство графика:** Функция не обладает ни осевой, ни центральной симметрией. Большинство функций относятся именно к этому типу.



*(Важное примечание: Для того чтобы функция могла быть четной или нечетной, ее область определения $D(f)$ обязательно должна быть симметрична относительно нуля. Например, если функция определена на $[-5; 7]$, она сразу считается функцией общего вида).*

**Примеры:**

* **Пример 1 (Четная функция):**
$f(x) = x^4 - 2x^2$
Подставляем $-x$: $f(-x) = (-x)^4 - 2(-x)^2 = x^4 - 2x^2 = f(x)$.
**Итог:** Функция четная, график симметричен относительно оси $Oy$.
* **Пример 2 (Нечетная функция):**
$f(x) = x^3 - 5x$
Подставляем $-x$: $f(-x) = (-x)^3 - 5(-x) = -x^3 + 5x = -(x^3 - 5x) = -f(x)$.
**Итог:** Функция нечетная, график симметричен относительно начала координат.
* **Пример 3 (Функция общего вида):**
$f(x) = x^2 + 3x$
Подставляем $-x$: $f(-x) = (-x)^2 + 3(-x) = x^2 - 3x$.
Это выражение не равно ни $f(x)$, ни $-f(x)$.
**Итог:** Функция не является ни четной, ни нечетной.


### Этап 4. Периодичность функции

**Объяснение:**
Периодическая функция — это функция, график которой бесконечно повторяется через равные промежутки вдоль оси $Ox$. Этот промежуток называется **периодом** и обозначается буквой $T$.

Суть этого свойства в экономии времени: если функция периодическая, нам не нужно исследовать её на всей числовой прямой. Достаточно построить график на одном отрезке длиной $T$ (например, от $0$ до $T$), а затем просто «скопировать и вставить» получившийся кусочек влево и вправо до бесконечности.

**Математическое условие:**
Функция периодична, если существует такое число $T \neq 0$, что для любого $x$ выполняется равенство:
$f(x - T) = f(x) = f(x + T)$

**Лайфхак для студентов:**
В классическом математическом анализе периодичность имеет смысл проверять **только** если в уравнении функции присутствуют тригонометрические элементы ($\sin, \cos, \text{tg}, \text{ctg}$) или дробная часть числа. Все обычные многочлены, дроби, корни и логарифмы периодичными не бывают. В таких случаях в исследовании просто пишется одна строчка: *"Функция не является периодической (апериодическая)"*.

**Примеры:**

* **Пример 1 (Классика):**
$f(x) = \sin(x)$
Базовый (наименьший положительный) период синуса и косинуса равен $2\pi$. Графики этих функций — бесконечные волны, где каждый «гребень» и «впадина» повторяются ровно через $2\pi$.
**Итог:** Периодическая, $T = 2\pi$.
* **Пример 2 (Изменение периода):**
$f(x) = \cos(3x)$
Коэффициент перед $x$ «сжимает» график. Чтобы найти новый период, нужно базовый период косинуса разделить на этот коэффициент.
$T = \frac{2\pi}{3}$
**Итог:** Периодическая, волна повторяется чаще.
* **Пример 3 (Обычная функция):**
$f(x) = x^2 + 5x$
Это парабола. Она не может повторяться, её ветви просто уходят вверх.
**Итог:** Апериодическая.
